# Python Learning Lab

Repositório dedicado ao estudo, prática e consolidação dos fundamentos da linguagem Python, servindo como base para a criação de futuros projetos.

---

## 🎯 Objetivos

- **Dominar os Fundamentos:** Compreender sintaxe, variáveis, estruturas condicionais e laços de repetição.
- **Aprofundar em Estruturas de Dados:** Praticar o uso de listas, dicionários, tuplas e conjuntos.
- **Explorar POO:** Entender conceitos de Programação Orientada a Objetos (classes, herança e encapsulamento).
- **Manipulação de Arquivos e Dados:** Trabalhar com leitura/escrita de arquivos (TXT, JSON, CSV).
- **Desenvolver Projetos Práticos:** Aplicar o conhecimento em scripts úteis, automações e APIs.
