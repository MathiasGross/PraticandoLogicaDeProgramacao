# 🧠 Estudos de Lógica de Programação & Algoritmos

Repositório dedicado ao estudo contínuo e à prática de fundamentos da computação e lógica de programação. 

O foco inicial está na construção do raciocínio lógico através de pseudocódigo (**Portugol**) e na transição e aplicação dos mesmos conceitos em uma linguagem amplamente utilizada no mercado (**Python**).

---

## 🎯 Objetivos de Aprendizagem

- [x] Fixar conceitos de entrada, processamento e saída de dados.
- [x] Dominar estruturas de controle de fluxo (condicionais simples, compostas e encadeadas).
- [x] Implementar laços de repetição (iterações finitas e condicionais).
- [x] Transitar do ambiente didático de pseudocódigo para um editor de código profissional (**VS Code**).
- [ ] Aplicar a lógica desenvolvida em Portugol diretamente na sintaxe do **Python**.
